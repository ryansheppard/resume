# resume

My resume built with [Typst](https://typst.app/) and for no real reason, Bazel. Does Bazel provide any real value here? Not really. Is it fun to say my resume is built with Bazel? Yes.

You do need [pdfinfo](https://man.archlinux.org/man/pdfinfo.1.en) to run the tests. I could not find a statically linked binary, nor did I want to set up a whole build process for it. At least not yet.

Everything here also relies on [mise](https://mise.jdx.dev/), including Bazel.
